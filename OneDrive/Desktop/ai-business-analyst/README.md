# AI Business Analyst 📊

An end-to-end AI-powered business analytics application that allows users to ask business questions in natural language and receive SQL analysis, business insights, and visualizations.

## 🚀 Features

- Natural-language business questions
- AI-powered SQL generation
- SQL validation and safety checks
- SQLite database
- Pandas-based business analysis
- Revenue trend analysis
- Category analysis
- Customer analysis
- Regional analysis
- Root-cause analysis
- Interactive Plotly visualizations
- Streamlit dashboard
- OpenAI integration with offline SQL fallback
